# MARKETPLACE.MA — lokale MVP-Version

## Voraussetzungen
- Node.js 20 oder neuer
- Visual Studio Code

## Start auf macOS
1. ZIP entpacken und den Ordner `MARKETPLACE-MA` in VS Code öffnen.
2. Im Terminal in diesem Ordner folgende Befehle ausführen:

```bash
npm install
npm start
```

3. Im Browser öffnen: http://localhost:3000

Die Datei `marketplace.db` wird beim ersten Start automatisch erstellt.

## Enthalten
- Responsive Kleinanzeigen-Oberfläche
- Anzeigen erstellen, speichern und anzeigen
- SQLite-Datenbank
- Suche nach Text, Kategorie und Land
- Sprachumschaltung für Deutsch, Französisch, Englisch und Arabisch (Basisübersetzungen)

## Wichtiger Hinweis
Dies ist eine lokale Lern-/MVP-Version, keine fertige öffentliche Handelsplattform. Vor einem öffentlichen Start sind insbesondere Benutzerkonten und Autorisierung, sichere Bild-Uploads, Spam- und Missbrauchsschutz, Moderation, Datenschutz/Impressum sowie Produktionshosting erforderlich. Aktuell können alle Besucher Anzeigen erstellen; es gibt noch keine Anmeldung.
